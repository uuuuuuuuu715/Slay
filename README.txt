PLATO'S RAVE — REAL SECTION PAGES

Upload every file in this folder into the SAME GitHub repository as index.html.

Files:
- philosopher.html
- music.html
- books.html
- fashion.html
- section-pages.css
- matching top/bottom PNG pieces

The graphics are lossless crops from your exact uploaded posters.
For Philosopher, the mirror is intentionally kept with the TOP graphic.

To add content:
Open the relevant .html file and put content inside:

<article class="article-content">
    ...your content...
</article>

The middle grows automatically. The bottom artwork will always be pushed
down beneath however much content you add.

Book Spotlight has no bottom artwork in the supplied poster, so that page
correctly has only its top graphic and expandable content below.
